Method & current scope

From disks to a segment

Each point defines a disk of radius r. A valid segment must intersect every disk. At a fixed direction and offset, each disk intersects the line in an interval. The shortest segment meeting all intervals follows directly from their extreme endpoints; overlapping intervals give a zero-length segment.

The baseline samples directions and offsets. Hull reduction and golden-section search improve the line placement. The third method also evaluates support changes and feasibility boundaries, then refines promising angles. A shared smallest-enclosing-circle check detects zero-length solutions independently of the angular samples.

Feasibility, precision & next steps

A segment exists exactly when the convex hull's minimum width is at most 2r. A rotating-calipers scan computes this width in O(h) time after the hull. A missed grid search alone is never reported as impossibility. If R is the smallest enclosing-circle radius, max(0, 2(R − r)) gives a geometric lower bound on the optimal segment length.

All calculations use floating-point numbers. The distance check allows 10⁻⁷ drawing units of error. The 10⁻⁴ offset tolerance bounds the final search interval, not the length error. Support and feasibility events are computed analytically; angular refinement is numerical. The report discusses the complete exact circular-arc event algorithm, which is not implemented here.

Based on van Beusekom et al., Capturing the Shape of a Point Set With a Line Segment (2025), §2 and §2.1, and their EuroCG 2024 extended abstract. See the implementation notes for the geometry, complexity and numerical limitations, and the README to run the code and experiments.
