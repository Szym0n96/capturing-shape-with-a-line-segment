Method & current scope

From disks to a segment

Each point defines a disk of radius r. A valid segment must intersect every disk. At a fixed direction and offset, each disk intersects the line in an interval. The shortest segment meeting all intervals follows directly from their extreme endpoints; overlapping intervals give a zero-length segment.

The baseline samples directions and offsets. The improved method first keeps only convex-hull vertices, then uses golden-section search on the offset. This works because the required length is a convex function of the offset inside the feasible strip.

Feasibility, precision & next steps

A segment exists exactly when the convex hull's minimum width is at most 2r. Here, all hull-edge directions are checked in O(h²) time. A missed grid search alone is never reported as impossibility. A single point is recognized when the computed intervals overlap; a positive result does not rule out a zero-length solution between samples.

All calculations use floating-point numbers. The distance check allows 10⁻⁷ drawing units of error. The 10⁻⁴ offset tolerance bounds the final search interval, not the length error. The exact circular-arc construction, rotating-calipers event queue and collision-detection extension are left for later work.
